# Funnel Analysis Framework

Stage-by-stage diagnosis of where a funnel leaks and what copy can and cannot fix. Load for `@ogilvy funnel`.

---

Every page, email, or surface exists at a stage in the buyer's journey. Copy that ignores funnel stage fails.

### Stages

| Stage | Buyer's Question | Copy Goal | Proof Type |
|-------|-----------------|-----------|------------|
| **Awareness** | "What is this?" | Name the category, describe the pain | Empathy, recognition |
| **Interest** | "Could this help me?" | Show the outcome, hint at mechanism | Specificity, mechanism |
| **Consideration** | "How does it compare?" | Differentiate honestly, prove claims | Comparison, social |
| **Decision** | "Is this worth it?" | Reduce risk, show value | Social proof, absence proof |
| **Action** | "What do I do?" | Clear CTA, low friction | Specificity (what happens next) |

### Funnel Audit Checklist

When reviewing a page:

1. **What stage is this?** If mixed, the page tries to do too much. Split it.
2. **Does copy match stage?** Awareness copy on a pricing page confuses. Decision copy on a landing page overwhelms.
3. **Is there a clear next step?** Every page must end with a specific CTA for the next stage.
4. **What's the drop-off risk?** Where does the reader lose interest or confidence?
5. **Is proof appropriate?** Early stages need empathy. Late stages need evidence.

### Page-to-Stage Mapping

| Page Type | Primary Stage | Secondary Stage |
|-----------|--------------|-----------------|
| Landing page / Homepage | Awareness | Interest |
| Features page | Interest | Consideration |
| Pricing page | Consideration | Decision |
| Comparison page | Consideration | Decision |
| Case study | Decision | Action |
| Signup / Onboarding | Action | — |
| Feature announcement | Interest | Consideration |
| Email nurture | Varies by sequence position | — |
