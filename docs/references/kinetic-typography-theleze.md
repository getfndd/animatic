# Kinetic typography experiment — @theleze

A motion reference that used to live in the animate skill as a saved web page.
The page is gone; this note is what remains of it.

## What it was

An interactive kinetic typography experiment credited to **@theleze**, captured
from Pinterest as a complete "save page as" archive — HTML plus its inline
assets, 516 KB in one file.

Catalogued in the inspiration library as *"Kinetic type — full experiment"*,
personality affinity **editorial**.

## Source

Not recoverable with certainty from the capture. The file carried no
`<link rel="canonical">`, no `og:url`, and no link to the creator's profile —
only ~40 pin URLs belonging to the page's recommendation rail, none of them
marked as the subject.

The most frequently occurring is `pinterest.com/pin/914862421673587` (3
occurrences against 1 for every other). That is a **candidate, not a
verification** — recorded so the trail is not lost, and flagged so nobody
repeats it as fact.

Searching Pinterest for "theleze kinetic typography" is the reliable route back.

## Why the capture is not here

A saved application page is neither a portable skill reference nor a stable
source artifact:

- **It is not portable.** `.claude/skills/` is copied into every project that
  syncs. A 516 KB archive carrying roughly 3,300 third-party URLs —
  `s.pinimg.com`, `arkoselabs`, `amazon-adsystem` — is not something to
  distribute to client repositories.
- **It is not stable.** It is a snapshot of one session's rendered DOM,
  including the recommendation rail and tracking pixels of that moment. Nothing
  in it is addressable, and it cannot be refreshed — only re-saved into
  something different.
- **It was invisible to every control.** The file was not lock-owned, so
  `team sync` could not see it; every guard in the studio reads canonical.
  `team audit` (fndd-LLC/fndd-studio#190) exists because of files like this one.

The GIFs and MP4s beside it in the inspiration library are unaffected: they are
single assets, individually catalogued, and each carries its own breakdown.

## If the reference is needed again

Capture a **short screen recording or a still**, not the page. Put it in the
inspiration library with a row in `INDEX.md`, the way every other reference
there works.
