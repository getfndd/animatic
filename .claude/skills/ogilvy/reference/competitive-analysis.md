# Competitive Analysis Framework

How to read a competitor's positioning and find the gap worth occupying. Load for `@ogilvy competitive`.

---

Honest competitive analysis. Never rig the comparison.

### Feature Matrix Rules

| Rule | Rationale |
|------|-----------|
| Include features where competitors win | Honesty builds trust. Cherry-picking destroys it. |
| Use factual categories, not marketing spin | "Data room sharing" not "Enterprise-grade document management" |
| Mark "partial" honestly | If they have it but worse, say "partial" — not "no" |
| Date the comparison | Features change. Stale comparisons mislead. |

### Competitive Analysis Structure

For each competitor:

1. **What they do well** — Give credit. Readers know competitors exist.
2. **What they don't say** — Positioning gaps reveal strategic weaknesses.
3. **User pain with them** — Real frustrations from real users (forums, reviews, interviews).
4. **Our genuine edge** — Pick 2-3 differentiators. Not everything. If everything is different, nothing is.
5. **Where we lose** — Acknowledge it. Then explain why it doesn't matter for our target user.

### Positioning Against Competitors

| Approach | When | Example |
|----------|------|---------|
| **Category creation** | No direct competitor | "The first founder operating system" |
| **Reframe the category** | Strong incumbent | "Not a cap table tool — a fundraising workspace" |
| **Direct comparison** | Switching users | "Like Carta, but you don't need a finance team" |
| **Integration tax** | Fragmented competitors | "5 tools, 5 logins, 5 bills. Or just [Product]." |
