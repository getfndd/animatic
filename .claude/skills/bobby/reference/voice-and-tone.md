# Voice & Tone Framework

Voice is constant; tone adapts to context. Load for `@bobby tone`, or when calibrating copy for a specific emotional register.

---

### Voice (Constant)

Voice is who we are. It doesn't change based on context.

| Attribute | Meaning | Not This |
|-----------|---------|----------|
| **Professional** | We handle important things (money, equity, legal) | Stuffy, corporate, cold |
| **Clear** | We say exactly what we mean, no ambiguity | Dumbed down, condescending |
| **Human** | We write like a knowledgeable colleague, not a machine | Chatty, slangy, overly casual |
| **Confident** | We know what we're doing and it shows | Arrogant, dismissive, braggy |

### Tone (Contextual)

Tone is how we adapt to the situation. Same voice, different emotional register.

| Context | Tone | Characteristics | Example |
|---------|------|-----------------|---------|
| **Onboarding** | Encouraging | Warm, forward-moving, celebratory at milestones | "You're set up. Here's what to do next." |
| **Success** | Affirming | Brief, specific, moves on | "Round created" |
| **Errors** | Empathetic + specific | No blame, clear path forward, never cutesy | "We couldn't save this. Check your connection and try again." |
| **Financial data** | Precise + trustworthy | Numbers exact, no approximation language, no hedging | "Ownership: 12.5% fully diluted" |
| **Legal/compliance** | Careful + authoritative | Plain language but exact, links to full terms | "By signing, you agree to the terms of this NDA." |
| **AI-generated content** | Process-focused | Describe the action, not the AI doing it | "Analyzing terms..." not "AI is processing..." |
| **Empty states** | Inviting | Show value, suggest action, never apologize | "Track your investors and where each conversation stands." |
| **Warnings** | Measured | State consequence without alarm, respect user agency | "This will permanently delete 5 documents." |
| **Instructions** | Direct | Imperative verbs, numbered steps when sequential | "Enter the amount. Select the instrument type. Review and confirm." |
| **Neutral (default)** | Matter-of-fact | Informational, no emotional loading | "3 investors added this week" |

### Voice Test

Before shipping copy, apply these checks:

1. **The colleague test**: Would a smart, helpful colleague say this?
2. **The re-read test**: Does the user need to read it twice?
3. **The alien test**: Would someone unfamiliar with the product understand this?
4. **The tone-deaf test**: Would this feel wrong if the user just encountered an error? Lost money? Got good news?
